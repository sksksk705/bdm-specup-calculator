# 은화 스펙업 계산기 — 검은사막 모바일

검은사막 모바일(Black Desert Mobile)에서 **전투력 1당 필요 은화**를 기준으로,
지금 가진 장비·가문 콘텐츠 상태에서 어떤 스펙업이 가장 효율적인지 계산해주는 웹 계산기입니다.

## 구조 (3-tier)

빌드 도구 없이 브라우저 네이티브 ES 모듈(`<script type="module">`)만으로 계층을 나눴습니다.

```
index.html              화면 골격(마크업)
css/style.css           스타일
data/prices.json        재료 시세("가격표") — 사이트가 직접 관리하는 데이터, 이 파일만 고치면 갱신됨
js/data/                데이터 계층 — gameData.js(게임 밸런스 상수), priceRepository.js(시세 fetch),
                         userState.js(localStorage 기반 사용자 상태)
js/logic/calculations.js 애플리케이션 계층 — 순수 계산 함수(DOM/저장소 접근 없음, 인자로만 값을 받음)
js/ui/                  프레젠테이션 계층 — 탭·타일·표를 그리고 사용자 입력을 처리
js/main.js               진입점 — 시세 fetch → 상태 초기화 → 화면 렌더링 순서로 부트스트랩
```

가격표(`data/prices.json`)와 사용자의 현재 장비 상태(브라우저 `localStorage`)는 분리되어 있습니다 —
가격표는 이 저장소를 관리하는 쪽에서 갱신하고, 사용자 입력은 각자의 브라우저에만 남습니다.

## 실행 방법

**`data/prices.json`을 `fetch`로 불러오기 때문에 `file://`로 직접 열면 브라우저 CORS 정책에 막혀
동작하지 않습니다.** 반드시 http(s) 서버로 열어야 합니다.

- **GitHub Pages(권장)**: 이 저장소의 Settings → Pages에서 소스를 `main` 브랜치 `/ (root)`로
  지정하면 `https://<계정>.github.io/<저장소명>/`에서 바로 열립니다.
- **로컬 확인**: 저장소 루트에서 정적 서버를 하나 띄우고(`python -m http.server` 등)
  `http://localhost:<포트>/index.html`로 접속합니다.

**① 현재 상태** 탭에서 인게임 장비 화면과 같은 배치로 부위별 등급·단계·레벨을 입력하고
아래 재료 시세 표에서 시세를 확인/조정하면, **② 스펙업 방식** 탭에서 모든 항목의 다음 한 스텝
비용과 "은화 / 전투력 1"이 자동으로 계산·정렬됩니다(값이 낮을수록 효율이 좋은 스펙업).

장비·장신구 등 사용자의 현재 상태 입력값은 브라우저 `localStorage`에 저장되어 새로고침해도
유지됩니다(같은 브라우저·기기 한정). 재료 시세 표의 값도 처음엔 `data/prices.json`에서
불러오지만, 표에서 직접 고친 값은 이후 그 브라우저에서는 localStorage에 저장된 값이 우선합니다.

## 다루는 항목

- 장비 6부위(주무기/보조무기/투구/갑옷/장갑/신발) 등급업(혼돈→공허) 및 잠재력 돌파(검은별은 전투력 상승이 없는 사이드그레이드라 제외)
- 전승의 고리(등급별 각성 단계·등급업)
- 밤/달빛 영혼석
- 반지·목걸이·허리띠·귀걸이·팔찌(장신구), 유물1/2 — 잠재력 돌파 + 등급업, 고대의 모루 천장 기반 자동 계산
- 유물 공허 등급 전용 "계열 돌파"(유물 마력 각인)
- 토템(균열의 토템), 조화의 연금석, 광원석, 실비아 여신상, 균형의 돌, 휘장

## 데이터 출처 및 가정

등급업 재료, 잠재력 돌파 확률표, 고대의 모루 천장 수치 등은 검은사막 모바일 공식
모험가 가이드(blackdesertm.com)에서 확인한 값입니다. 확인 시점과 출처는 계산기 하단
"데이터 출처 및 가정" 섹션에 wikiNo와 함께 정리되어 있습니다.

장비 6부위(혼돈·공허 등급)와 장신구·휘장·토템(태고·혼돈·공허 등급)의 잠재력 돌파 단계별
전투력 증가치는 공식 포럼 모험가 가이드 22편·23편의 실측 데이터를 그대로 옮긴 근사값이라
더 이상 직접 입력이 필요 없습니다. 그 외 재료 시세·전투력 증가량 중 공식 문서에 없는 값은
**더미값(placeholder)** 으로 채워 두었습니다 — 계산 흐름을 바로 확인할 수 있도록 임시로 넣은
숫자이니, 실제 값을 알게 되면 ① 탭의 재료 시세 표와 각 항목의 전투력 입력칸에서 직접 교체해
주세요.

## 참고

개인적으로 스펙업 우선순위를 정리하려고 만든 도구이며, 게임사 공식 계산기가 아닙니다.
게임 패치로 재료·확률·비용이 바뀌면 계산기 값도 함께 갱신해야 합니다.
